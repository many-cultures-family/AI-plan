## 항목 1: 작성 목록 조회 (기능 ID: F-08)

| 항목 | 내용 |
| --- | --- |
| 요청 (경로·방식) | `GET /api/drafts` `[제안]` — `DOC-UPLOAD-API.md` "아직 없는 항목"에 있던 "작성 건 조회"를 여기서 채운다 |
| 입력 | 쿼리: `status`(수정·반려·성공, 생략하면 **`취소`를 뺀 전체**) `[제안]` — `취소`는 필터 값에도 넣지 않는다. 아래 참고 |
| **`취소` 건은 목록에서 아예 뺀다** | `DATA-MODEL.md` 123행("`취소` 상태는 ... 작성 목록에서 숨긴다")과 US-07 1번째 인수 조건("취소되고 작성 건이 작성 목록에 남지 않는다")이 둘 다 "숨긴다"고 적고 있어, `status=취소`로 걸러 볼 방법 자체를 안 둔다. 그래서 `next_action` 표에도 취소에 대응하는 코드가 없다(의도적으로 없음) |
| `status`에 허용 목록(`수정`·`반려`·`성공`) 밖의 값을 보내면 | `취소`든 그 외 아무 값(예: `foo`)이든 `400 STATUS_NOT_ALLOWED` `[제안]`로 거절한다 — 조용히 무시하고 기본 목록을 돌려주면 클라이언트가 자신이 허용 안 된 값을 보냈다는 걸 모르고 넘어갈 수 있다. **구현 시 주의**: FastAPI의 `Literal` 타입으로 이 쿼리를 검증하면 기본 `422` 오류가 `{"detail": [...]}`(배열) 모양으로 나와 공통 규칙의 `{"detail": {"code": ...}}` 모양과 어긋난다. `status: str \| None`으로 받고 허용 목록과 수동으로 대조해 `400 STATUS_NOT_ALLOWED`를 직접 던지는 방식으로 구현한다 |
| 출력 (성공) | `200`. **로그인한 사용자 본인 소유의 작성 건만** 돌려준다 (다른 사용자의 작성 건은 목록에도 안 나온다 — 조회 자체를 막는 `FIELD-CHECK-API.md`의 `403 FORBIDDEN_DRAFT`와 달리, 목록은 애초에 본인 것만 쿼리한다). `drafts` 배열: `id`, `status`, `step`, `reject_reason`, `submitted_at`, `next_action`(아래 표) |
| `next_action` 코드 | `step`·`status`로 서버가 계산해서 주는 코드. 문구는 프론트 국제화가 만든다 (R3와 같은 방식): `UPLOAD`(수정+upload), `FIELD_CHECK`(수정+field_check), `PRIOR_INFO`(수정+prior_info), `WRITING`(수정+writing), `REVIEW`(수정+review), `REJECTED`(반려), `SUBMIT`(성공, `submitted_at` 없음), `DONE`(성공, `submitted_at` 있음) `[제안]`. `취소`는 목록 자체에 안 나오므로 코드가 없다 |
| 실패 응답 | `401 LOGIN_REQUIRED`. `status`가 허용 목록 밖이면 `400 STATUS_NOT_ALLOWED`(위 참고). 그 외는 없음(빈 배열도 `200`) — 목록 API라 특정 작성 건에 대한 `403`/`404`는 해당 없음 |
| 관련 인수 조건 | 인수 조건 없음(목록·필터는 backlog에 스토리 자체가 없음). F-08 설명(`mvp-assumptions-questions.md` 30행 "내 작성 목록에서 작성 건의 지금 단계와 다음 할 일을 보여 준다")만 근거 |
| 화면이 쓰는 곳 | `DESIGN.md` 내 작성 목록 |

| 입력 | 없음 |
| 동작 | `draft.status`를 `취소`로 바꾼다(R12, 되돌릴 수 없음). `수정`·`반려`·`성공` 어느 상태에서든 호출할 수 있다(R12 "제출 전 모든 상태 → 취소"). | 출력 (성공) | `200`. `{"id": .., "status": "취소"}` |

| 실패 응답 ("유효하지 않은(이미 삭제되었거나 옳지 않은 참조) 작성 건", US-07 인수 조건) | `401 LOGIN_REQUIRED`, `403 FORBIDDEN_DRAFT`, `404 DRAFT_NOT_FOUND`. 이미 `취소`면 `409 ALREADY_CANCELED` `[제안]` |
