- 작성일: 261102
- 고른 스토리: `US-01` (기능 ID `F-01`)

- 고른 이유 (우리 팀 상황에서): 저희 서비스 특성 상 기능에 순서가 있어 특정한 기능을 하나 선택하는 것보다 처음부터 하기로 했습니다.
- 고르지 않은 후보와 이유 (다음 시간 이후에 다시 볼 것)

    - US-05: L3 호출과 모호한 인수 조건
    - US-06, US-07: 선택 스토리. US-07을 필수로 올릴지 정한 뒤 다시 봄
