# 사전 정보·입력값 서버 저장 여부

- 작성일: 2026-11-17
- 결정일: 2026-11-17
- 결정 방법: 회의에서 합의
- 참석자: 확인 필요
- 기록: 석준영 (sjy0128). 초안은 Claude가 쓰고, 날짜·방법은 석준영이 확인함

## 결정

**사전 정보와 입력값(서술형 답변 포함)은 서버에 저장하지 않는다.** 브라우저에만 둔다.

- 서버에 저장하는 개인정보 관련 데이터는 업로드 원본 파일과 OCR 직후 가린 텍스트(`masked_text`)뿐이다 (`docs/privacy/pii-items.md` 1절)
- 서술형 답변은 L3 호출을 위해 서버를 지나가지만, **브라우저에서 가린 글**만 지나가고 서버는 저장하지 않는다 (`docs/privacy/l3-masking.md`)

## 왜 결정이 필요했나

`docs/DATA-MODEL.md` 초안은 사전 정보를 서버에 암호화해 저장하고(`prior_info.value`, `[제안]`), 입력값도 서버 DB(`field_answer`)에 둔다고 적고 있었다. `docs/api/VIRTUAL-FORM-API.md`와 `backlog.md` US-04 인수 조건도 같은 전제를 쓴다. 그런데 이 내용은 Claude 초안이고, 팀이 정한 기록은 없었다. 개인정보 데이터 흐름도(`docs/privacy/data-flow.md`)를 그리면서 이 차이를 발견했다.

## 아직 정하지 않은 것

결정과 함께 생긴 문제다. 내용은 `docs/privacy/data-flow.md` 5절에 있고, 여기에는 번호만 적는다.

- 5절 #2: 서버에 입력값이 없어서 성공 판정(R9)을 서버가 확인할 수 없음
- 5절 #3: 브라우저 어디에 보관할지 (메모리·`localStorage`·IndexedDB). 다른 기기에서는 사전 정보를 다시 입력해야 함 (R11)
