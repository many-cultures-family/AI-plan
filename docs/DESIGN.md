## 모든 화면에 있어야 하는 상태
| 상태 | 어떻게 보이나 |
| --- | --- |
| 빈 화면 (데이터 없음) | 안내 문구("아직 올린 문서가 없어요" 등 화면별로 사용 언어로) + 다음 행동 버튼(예: 업로드) |
| 오류 | 오류 메시지를 사용 언어로 보여주고 '다시 시도' 버튼 제공. 서버가 꺼져 있으면 "서버 연결 실패" |
| 불러오는 중 | 로딩 스피너(버튼·전체 화면 모두 공통 컴포넌트 하나로 통일) |
| LLM 결과를 사람이 확인하기 전 | 상태가 바뀐 것처럼 보이지 않게 표시 (미정 가능) |
