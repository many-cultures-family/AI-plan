# 베트남어 범위 확정

| 항목 | 기준 |
| --- | --- |
| 대상 사용자 | 한국어로 일상 소통은 어느 정도 가능하지만 공문서의 형식·용어가 낯설어, 문서를 작성·제출하는 데 어려움을 겪는 베트남 결혼이민자 및 다문화가정 구성원 |
| 번역 방향 | 한국어 신청서 → 베트남어 설명 (사용자가 올리는 문서는 한국어)<br>한국어 단어나 문장 → 베트남어 설명 |
| 대상 분야 | 체류·국적, 가족관계등록, 자녀·복지 |
| 포함 기준 | 1. 공공기관 공식 서식<br>2. 빈 양식이 공개되어 있음 |
| 개인정보 | 빈 양식만 사용. 실제 작성된 서류는 수집하지 않음 |
| 제외 | 유학·근로 비자 전용 서식 |
